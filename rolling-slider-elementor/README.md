# اسلایدر رولینگ برای المنتور

ویجت اسلایدر تمام‌عرض (تصویر یا ویدیو) با تب‌های ناوبری شمارنده‌دار، متن و دکمه‌های قابل ویرایش برای هر اسلاید، افکت‌های ورود و پشتیبانی کامل از راست‌چین/چپ‌چین. این افزونه تبدیل‌شدهٔ یک قالب HTML/CSS/JS مستقل (`index.html` در ریشهٔ مخزن) به ویجت المنتور است.

**نیازمندی‌ها:** وردپرس ۶+، PHP 7.4+، المنتور ۳.۵+

## نصب

افزونه‌ها ← افزودن ← بارگذاری افزونه ← فایل `rolling-slider-elementor.zip` ← فعال‌سازی.
سپس در المنتور ویجت **«اسلایدر رولینگ»** (دسته‌بندی «عمومی») را در یک کانتینر تمام‌عرض بیندازید.

اگر المنتور فعال نباشد، نسخهٔ آن پایین‌تر از ۳.۵ باشد یا PHP قدیمی باشد، افزونه ویجت را ثبت نمی‌کند و فقط یک هشدار در پیشخوان نشان می‌دهد؛ سایت خراب نمی‌شود.

## ساختار فایل‌ها

```
rolling-slider-elementor.php   بوت‌استرپ: بررسی نیازمندی‌ها، ثبت ویجت، CSS و JS
includes/class-widget.php      کنترل‌های المنتور + رندر HTML (کلاس Rolling_Slider\Widget)
assets/css/rolling-slider.css  استایل (متغیرهای CSS و ویژگی‌های منطقی برای RTL/LTR)
assets/js/rolling-slider.js    رفتار اسلایدر (بدون وابستگی به کتابخانهٔ اسلایدر)
```

## نحوهٔ کار

### ۱. بارگذاری افزونه
`rolling-slider-elementor.php` روی `plugins_loaded` نیازمندی‌ها را می‌سنجد و بعد سه چیز را به المنتور وصل می‌کند: ثبت ویجت، ثبت استایل و ثبت اسکریپت. CSS و JS فقط **ثبت** می‌شوند، نه بارگذاری؛ ویجت با `get_style_depends()` و `get_script_depends()` آن‌ها را اعلام می‌کند و المنتور فقط در صفحه‌هایی که ویجت دارند بارگذاری‌شان می‌کند. ویجت `div` اضافهٔ `.elementor-widget-container` را هم ندارد (DOM سبک‌تر).

### ۲. کنترل‌ها (سمت ویرایشگر)
در `class-widget.php`، تابع `register_controls()` سه بخش محتوا و هفت بخش استایل می‌سازد.

**تب محتوا**
- **اسلایدها:** یک Repeater. هر اسلاید سه زیرتب دارد:
  - *رسانه:* تصویر یا ویدیو (MP4/WebM)، ویدیوی سبک موبایل (اختیاری)، پوستر و کانون تصویر (`object-position` ریسپانسیو).
  - *متن:* زیرعنوان، عنوان (با `<b>` برای رنگ تاکیدی و `<br>` برای شکستن خط) و محتوا (ویرایشگر WYSIWYG).
  - *دکمه‌ها:* حداکثر دو دکمه با متن، لینک، ظاهر اصلی/شفاف و آیکن (پیش‌فرض‌های آماده یا آیکن دلخواه).
- **تنظیمات اسلایدر:** پخش خودکار و مدت هر اسلاید، توقف با هاور، سوایپ، نمایش تب‌ها، افکت و سرعت گذار (محو، محو+زوم، محو+بلور)، Ken Burns، جهت ویجت، برچسب دسترس‌پذیری و «اسلاید نمایشی در ویرایشگر».
- **تگ‌ها و تصویر:** تگ زیرعنوان و عنوان، و اندازهٔ تصویر.

**تب استایل:** کادر و چیدمان، رسانه و پوشش (گرادیان‌ها و فیلتر CSS)، زیرعنوان، عنوان، محتوا، دکمه‌ها و تب‌ها. بیشتر مقادیر به‌صورت **متغیر CSS** (مثل `--rsl-accent`, `--rsl-deep`, `--rsl-duration`) روی ریشهٔ ویجت نوشته می‌شوند، نه با قوانین سنگین؛ پس تغییر یک رنگ یا فاصله، یک متغیر را عوض می‌کند.

افکت ورود هر بخش (زیرعنوان، عنوان، محتوا، دکمه‌ها) جدا قابل انتخاب است: بدون افکت، محو، محو از پایین/بالا، لغزش، زوم، بلور، چرخش سه‌بعدی و پردهٔ Reveal؛ همراه با مسافت، مدت و تأخیر.

### ۳. ساختار HTML خروجی
تابع `render()` یک `<section class="rsl">` می‌سازد:

```
section.rsl[dir][data-autoplay][data-duration][data-pause-hover][data-swipe]
├─ .rsl__stage            لایهٔ رسانه (aria-hidden)
│   └─ .rsl__slide ×N     هر اسلاید: <img> یا <video>
├─ .rsl__veil             پردهٔ گرادیان روی رسانه
├─ .rsl__body
│   └─ .rsl__panels
│       └─ .rsl__panel ×N (role=tabpanel)
│           ├─ .rsl__eyebrow   زیرعنوان
│           ├─ .rsl__title     عنوان (h1/h2/…)
│           ├─ .rsl__content   محتوا
│           └─ .rsl__actions   دکمه‌ها (.rsl__btn--primary / --ghost)
└─ .rsl__nav
    └─ .rsl__tabs (role=tablist)
        └─ button.rsl__tab ×N (role=tab)
```

نکات مهم رندر:
- **همهٔ پنل‌ها هم‌زمان در DOM هستند** و فقط پنل فعال کلاس `is-active` می‌گیرد؛ پس متن همهٔ اسلایدها برای موتورهای جستجو قابل خواندن است و گذار با CSS انجام می‌شود، نه با ساختن دوبارهٔ HTML.
- **سئو:** اگر تگ عنوان `H1` انتخاب شود، فقط اسلاید اول `H1` است و بقیه خودکار `H2` می‌شوند.
- **بارگذاری تنبل رسانه:** فقط اسلاید اول `src` واقعی دارد (`loading="eager"` و `fetchpriority="high"`). بقیه یک GIF شفاف یک‌پیکسلی دارند و آدرس واقعی در `data-rsl-src` / `data-rsl-srcset` است. ویدیوها `preload="none"` هستند و آدرس‌شان در `data-rsl-src` می‌آید.
- **`srcset`:** برای تصاویر کتابخانهٔ رسانه از `wp_get_attachment_image_srcset` ساخته می‌شود و مرورگر اندازهٔ مناسب را برمی‌دارد.
- **امنیت:** عنوان با `wp_kses` و فهرست کوچک تگ‌های مجاز (`br`, `b`, `strong`, `em`, `i`, `mark`, `span`) پاک‌سازی می‌شود، محتوا با `wp_kses_post`، و آدرس‌ها و صفت‌ها escape می‌شوند.
- **کلیدهای خالی:** `normalize_item()` برای هر اسلاید مقدار پیش‌فرض می‌گذارد تا رندر هرگز Notice ندهد.
- **ویرایشگر:** در حالت ویرایش، پخش خودکار خاموش است و اسلاید انتخاب‌شده در «اسلاید نمایشی در ویرایشگر» نشان داده می‌شود.

### ۴. رفتار (JavaScript)
`rolling-slider.js` برای هر ویجت یک نمونهٔ مستقل می‌سازد (بدون ID ثابت). نمونه با `data-rsl-ready` علامت می‌خورد تا دوبار راه‌اندازی نشود، و با هوک `frontend/element_ready/rolling_slider.default` در فرانت‌اند و ویرایشگر المنتور اجرا می‌شود. اگر المنتور ویجت را دوباره رندر کند و ریشه از DOM جدا شده باشد، تایمر و شنونده‌های نمونهٔ قدیمی پاک می‌شوند (`destroy()`).

- **تعویض اسلاید (`go(i)`):** کلاس `is-active` را روی اسلاید، پنل و تب جابه‌جا می‌کند، `aria-selected` و `tabindex` را به‌روز می‌کند، رسانهٔ همین اسلاید و اسلاید بعدی را بارگذاری می‌کند و تایمر را از نو می‌سازد.
- **تایمر با «زمان باقی‌مانده»:** هنگام مکث، زمان گذشته کم می‌شود و با ادامه، همان باقی‌مانده زمان‌بندی می‌شود؛ بنابراین با نوار پیشرفت CSS (که همان لحظه متوقف و ادامه می‌یابد) هم‌گام می‌ماند. مکث چند دلیل مستقل دارد: هاور، فوکوس کیبورد، تب پنهان، خارج از دید بودن، و لمس. کلیک ماوس روی تب باعث توقف همیشگی نمی‌شود.
- **ویدیو:** فقط ویدیوی اسلاید فعال پخش می‌شود و لوپ دارد؛ هاور فقط چرخش اسلایدها را نگه می‌دارد، نه خود ویدیو را. روی صفحهٔ کوچک، اگر ویدیوی سبک موبایل تعریف شده باشد همان استفاده می‌شود. با Data Saver، اتصال 2G یا تنظیم «کاهش حرکت»، ویدیو اصلاً بارگذاری نمی‌شود و پوستر می‌ماند.
- **پیش‌بارگذاری:** بقیهٔ رسانه‌ها فقط روی دسکتاپ و اینترنت عادی، در زمان بیکاری مرورگر، بارگذاری می‌شوند.
- **`IntersectionObserver`:** وقتی اسلایدر از دید خارج است، نه تایمر می‌چرخد و نه ویدیو پخش می‌شود.
- **کیبورد:** فلش‌ها بین تب‌ها جابه‌جا می‌شوند و جهت از `dir` واقعی ویجت می‌آید (در راست‌چین فلش چپ = بعدی)؛ `Home` و `End` هم کار می‌کنند.
- **سوایپ:** کشیدن افقی بیش از ۴۸ پیکسل (و بیشتر از حرکت عمودی) اسلاید را عوض می‌کند. لمس صفحه تایمر را چهار ثانیه نگه می‌دارد.

### ۵. استایل (CSS)
- بیشتر ظاهر از **متغیرهای CSS** روی `.rsl` می‌آید (رنگ تاکیدی، پس‌زمینه، رنگ پوشش، شدت گرادیان‌ها، عرض کانتینر، حاشیه‌ها، سرعت گذار، مدت پخش خودکار).
- جهت‌ها فقط با **ویژگی‌های منطقی** (`inline-start/end`, `margin-inline`) و متغیرهای وابسته به `[dir]` نوشته شده‌اند؛ بنابراین یک CSS برای RTL و LTR کافی است.
- گذار بین اسلایدها با `opacity` و `visibility` است؛ Ken Burns یک `scale` بسیار آهسته روی تصویر فعال است.
- ریل پیشرفت هر تب با `::before` (خط کم‌رنگ) و `::after` (پرشونده با `@keyframes rsl-fill` و `--rsl-duration`) ساخته می‌شود. مکث با کلاس `is-paused` انیمیشن را متوقف می‌کند و در حالت `rsl--static` (بدون پخش خودکار) تب فعال کاملاً پر نشان داده می‌شود.
- **ریسپانسیو:** زیر ۷۶۸ پیکسل بلوک متن به پایین می‌چسبد و تب‌ها به‌جای اسکرول افقی در یک شبکهٔ سه‌ستونی می‌نشینند (بدون سرریز)؛ زیر ۳۸۰ پیکسل فاصله‌ها فشرده‌تر می‌شود.
- **`prefers-reduced-motion`:** گذارها، Ken Burns و انیمیشن ریل غیرفعال می‌شوند.

## راست‌چین / چپ‌چین

جهت ویجت به‌صورت پیش‌فرض از هستهٔ وردپرس (`is_rtl()`) می‌آید و با عوض شدن زبان سایت (مثلاً WPML/Polylang) خودکار عوض می‌شود. ترازها «ابتدا / وسط / انتها» هستند (راست/چپ بسته به جهت). برای یک ویجت خاص می‌توانید در *تنظیمات اسلایدر ← جهت ویجت* جهت را اجباری کنید. آیکن فلش دکمه‌ها هم خودکار با جهت برمی‌گردد.

## تغییر و توسعه

- **اضافه کردن کنترل:** در `class-widget.php` یک کنترل به متد مناسب اضافه کنید و `selectors` آن را به یک متغیر CSS یا قاعدهٔ `.rsl__…` وصل کنید.
- **اضافه کردن افکت ورود:** نام آن را به ثابت `Widget::FX` و گزینه‌های `add_fx()` اضافه کنید و کلاس `.rsl-fx--نام` را در CSS بنویسید.
- **افزایش نسخه:** `RSL_VERSION` و هدر افزونه را با هم عوض کنید تا کش مرورگر برای CSS و JS پاک شود.
