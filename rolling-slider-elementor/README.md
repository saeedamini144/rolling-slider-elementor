# اسلایدر رولینگ برای المنتور

ویجت اسلایدر تمام‌عرض (تصویر یا ویدیو) با تب‌های ناوبری، تبدیل‌شدهٔ قالب HTML اولیه.

**نیازمندی‌ها:** وردپرس ۶+، PHP 7.4+، المنتور ۳.۵+

## نصب
افزونه‌ها ← افزودن ← بارگذاری افزونه ← فایل `rolling-slider-elementor.zip` ← فعال‌سازی.
سپس در المنتور ویجت **«اسلایدر رولینگ»** را در یک کانتینر تمام‌عرض بیندازید.

## ساختار
```
rolling-slider-elementor.php   بوت‌استرپ، ثبت ویجت و فایل‌ها
includes/class-widget.php      کنترل‌ها و رندر ویجت
assets/css/rolling-slider.css  استایل (فقط ویژگی‌های منطقی؛ RTL/LTR با attribute dir)
assets/js/rolling-slider.js    رفتار اسلایدر
```
CSS و JS فقط در صفحه‌هایی که ویجت دارند بارگذاری می‌شوند.

## راست‌چین / چپ‌چین
جهت ویجت به‌صورت پیش‌فرض از هستهٔ وردپرس (`is_rtl()`) می‌آید؛ با عوض شدن زبان سایت (مثلاً WPML/Polylang) خودکار عوض می‌شود.
ترازها «ابتدا / وسط / انتها» هستند (راست/چپ بسته به جهت). برای یک ویجت خاص می‌توانید در *تنظیمات اسلایدر ← جهت ویجت* جهت را اجباری کنید.
